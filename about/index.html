ABOUT

Small tools for the parts of website work that should be simple

CardKit started with a recurring problem: small website changes often require tools that are much larger than the job.

Changing one line of text should not require rebuilding a page. Replacing one image should not require learning a design platform. Updating one button link should not mean searching through hundreds of lines of code.

CardKit creates focused browser utilities for those small tasks. The idea is simple:

bring in what you need, make a controlled change, check the result and take it back to the platform you already use.

The first tools grew out of real template-design and website-production workflows, including custom HTML sections, responsive website layouts and digital-product preparation.

CardKit is designed for designers, freelancers, template buyers, small-business owners and anyone who occasionally needs to make a website change without turning it into a development project.

Principles

Focused

One tool should solve one understandable problem.

Lightweight

No unnecessary dashboard, account system or setup process.

Transparent

Users should know what the tool does and what happens to their data.

Practical

Features should come from real production tasks rather than feature lists.

Reversible

Where possible, users should be able to keep the original and leave with a portable result.

Privacy

Where a tool can reasonably process data locally in the browser, that is the preferred approach.

For example, the CSS Code Editor processes pasted HTML inside the browser instead of sending it to CardKit servers.

Some functionality may still request third-party resources referenced by user content or required to render a preview. See the Privacy Policy for details.

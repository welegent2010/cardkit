FAQ

Does resizing reduce image quality?

Reducing dimensions normally removes image data. Export quality also depends on the selected output format and compression level. Keep the original file if you may need a larger version later.

Will CardKit stretch the image?

Not when aspect-ratio lock is enabled. Turn the lock off only when you want the two sides to move independently, which will change the proportions on purpose.

Is the uploaded image stored?

The tool processes images locally and does not store uploaded image files on CardKit servers. Refreshing the page clears everything.

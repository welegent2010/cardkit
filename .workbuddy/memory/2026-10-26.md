# 2026-10-26

## Search Console「网页会自动重定向」排查（用户被 GSC 邮件吓到，实际无害）
- 报告内容：已编入索引 3 页；未编入索引 1 页，原因「网页会自动重定向」。
- 根因：Cloudflare Pages 会把 `/404.html` 308 重定向到 `/404`；而 404.html 自己的 canonical/og:url 偏偏指向 `/404.html`，Google 顺着 canonical 就撞上重定向。
- 修复：404.html 的 canonical 和 og:url 改为 `https://cardcss.top/404`（/404 直接 200 返回 404 页内容；不存在路径正确返回 HTTP 404 状态）。已部署并 curl 验证。
- 结论传达给用户：这不是域名问题也不是惩罚；404 页本就不该被索引，无需处理。
- 其他实测：sitemap 16 个 URL 无一重定向；www 直接 200 不跳 apex（canonical 都指向 apex，无重复风险）；http→https 301 正常。
